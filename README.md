## 💡 My Learning Philosophy

> **Learn → Practice → Build → Document → Repeat**

I believe that learning technology is not just about watching tutorials or reading documentation.

My approach is:

1. **Learn** the concept
2. **Understand** how and why it works
3. **Practice** by writing code
4. **Build** something with it
5. **Document** what I learned
6. **Review** and improve
